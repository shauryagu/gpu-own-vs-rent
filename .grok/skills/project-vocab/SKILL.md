# Project vocabulary

Canonical glossary: `docs/vocab.md`. That file is the only home for definitions.

## What to do

1. Read `docs/vocab.md`.
2. Use that file's name, unit, and "Not this" column.
3. If the term is not in the file, stop and ask. Do not invent a synonym.

## Collisions that always require the file

- leftover \(L\) vs salvage \(R^{\star}\) vs "implied residual"
- \(F(\theta)\) vs Bandi & Su \(F_t(T)\)
- daily-index vs hourly current vs history
- declared \(P\) vs Epoch release price
- accounting overlay \(T=6, R=0\) vs primary \(\theta\)

Do not copy definitions into other docs or into this skill.
